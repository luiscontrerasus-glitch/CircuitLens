Credit: Simon Monk / Adafruit Learning System. No endorsement implied. Photographs retain their individual licenses; the project's MIT code license does not replace them. The RGB photograph and image adaptations retain CC BY-SA 3.0. Downloads are the CDN-served bytes without local edits; the CDN may optimize its originals. API inputs are resized to fit 1600 × 1600, re-encoded JPEG and stripped of metadata by the existing upload pipeline. Those changes are recorded here and in recognition provenance. No reference diagram or tutorial text was supplied to Gemini.

Values above are documented intended values, not proof every band can be read in every photograph. Loose LED-lesson resistors are the documented 470 Ω, 2.2 kΩ and 10 kΩ alternatives; they are not installed branches. Photos alone do not establish hidden contacts, rail continuity, switch state, LED polarity, microcontroller outputs, or a physically validated complete netlist. All six circuits contain unsupported external controller boards; complex circuits additionally contain unsupported ICs/sensors/pots/RGB packages. Treat them as explicit scope-boundary tests.

See `../production-launch/REAL_PHOTO_EVALUATION.md` for actual results, errors and assessment limits. The six test images and reports are excluded from the production package and are not exposed as public runtime assets. To repeat deliberately with an unbilled Gemini project: `node scripts/evaluate-real-photos.js --live`. Existing result files are skipped; archive an individual result explicitly before a deliberate retry. There are no automatic retries and no OpenAI fallback.
