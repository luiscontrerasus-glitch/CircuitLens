# The solution

The workbench makes the debugging process visible:

1. Review a local image or a labeled generated example.
2. Confirm components, breadboard terminals, resistance, supply voltage, and button state.
3. Choose an intended design when one is available.
4. Analyze the resulting electrical graph.
5. Read evidence, a beginner-friendly explanation, and a specific correction.
6. Change the model and re-run the same rules.

The photo mask is a visual aid, not recognition. The confirmation step is how the MVP obtains reliable structured input. Generated fixtures provide a dependable demonstration without pretending their diagrams have been understood by computer vision.
