# 60-second pitch

When an LED stays dark, beginners often move wires without understanding the circuit. CircuitLens helps them inspect the terminals and learn why a correction works.

The new visual layer sends a consented image to OpenAI and requests structured component boxes, terminal candidates, values and confidence. It never sees the intended design. A person reviews every observation; only then does a deterministic graph engine compare the circuit and explain electrical faults. The original manual workbench and seven guided circuits remain usable without AI.

We verified 39 automated tests and the production package. Five live requests were blocked by exhausted API credits, so we do not claim recognition accuracy. The current reliable demo shows reversed polarity, an open jumper, and a corrected graph. Our next evaluation is live extraction followed by consented real-photo testing.
