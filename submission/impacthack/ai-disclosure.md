# AI disclosure

Codex assisted with implementation, debugging, tests, documentation and original SVG/PNG teaching artwork generated by code. Runtime perception is implemented using the pretrained OpenAI model `gpt-4.1-mini-2025-04-14` through the Responses API. No fine-tuning, custom weights or external circuit-photo dataset was used. Model explanations do not replace the deterministic fault engine.

The runtime OpenAI integration is implemented, but successful live recognition has not been verified. On October 1, five Responses API attempts (correct image three times, reversed once, disconnected once) returned HTTP 429; the diagnostic response identified `credit_balance_exhausted` / `insufficient_quota`. Authentication and access to the selected model were separately verified with HTTP 200 from the models endpoint. No successful model observations, recognition accuracy, or real-hardware validation are claimed. Automated/provider-simulated checks and manual graph demos are separate evidence.

Confidence scores are model assessments, not calibrated probabilities. All detections require review. Hidden continuity, obscured LED polarity, resistor bands, split rails and unfamiliar layouts remain uncertain. Our three new image demos are explicitly labeled synthetic teaching diagrams, not photographs. Seven older examples use fixture netlists; they are not visual inference. Simulated responses exist only in tests and the explicitly labeled development harness. Recorded replay is available only after saving an actual successful API response; no such records exist in this version.

Manual photo review remains in browser memory. Explicit live-analysis consent sends a resized image through this server to OpenAI. The app does not persist uploaded photos; `store:false` is used, but this is not a promise of zero provider retention. Reports retain model/date/image-hash provenance, not credentials. The key is server-side in ignored `.env.local`; production uses a host secret. A named CircuitLens key was created in the selected Default project, with a 30-day expiry. A separate OpenAI project, restricted key permissions and provider spending cap were not configured by the available provisioning tool. Do not claim otherwise.
