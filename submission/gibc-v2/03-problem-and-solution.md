# Problem and solution

## Problem

Breadboard connections are often hidden by the visual arrangement. Two nearby holes can belong to separate nets; a reversed LED can look plausible. Beginners need to understand which terminal assumption caused a finding and what would change electrically after a correction.

## Solution

CircuitLens presents a photograph or generated example alongside an editable netlist. The intended reference stays separate. Reviewed terminals become a breadboard graph, and deterministic checks explain supported differences and faults. The visual API layer proposes structured observations to reduce manual transcription when it is available; the user reviews every suggestion.

The primary current evidence is working graph analysis, manual correction, seven fixtures and the reviewed-simulation flow. Successful live extraction remains blocked by API credits. This is an honest educational prototype, not a hardware tester or demonstrated learning intervention.

## Intended users and impact

Students in introductory electronics, beginner makers and instructors could use it to connect a wiring change with an electrical reason. Generated exercises support practice without hardware or API access. No classroom partnership, usage, adoption or learning improvement has been measured.
