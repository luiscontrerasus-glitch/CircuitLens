# GIBC Track 03 judging alignment

CircuitLens is packaged for **Open / General Technical Invention** as an existing working software prototype. Its core has not been changed to fit a different track. [Official Track 03 criteria](https://gibc-v2.devpost.com/) were reviewed October 1, 2026.

| Criterion    | CircuitLens contribution                                                                                                 | Show the evidence                                                           | Boundary                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Creativity   | A reviewable hybrid pipeline joins visual observations, human confirmation, graph reasoning and educational explanations | Schema and architecture; candidate editing before netlist conversion        | No claim of a novel trained model or proven first-of-its-kind invention       |
| Execution    | Working editor, seven demos, deterministic fault engine, review interface and graceful fallback                          | Reversed LED before/after; open path; 39 passing tests and production smoke | Live visual extraction remains credit-blocked and unverified                  |
| Impact       | Potential to teach beginners why a connection is wrong instead of giving an unsupported answer                           | Evidence/why/fix cards and learning-focused demo                            | No users, adoption, classroom studies or learning gains claimed               |
| Presentation | Clear 3:30 product walkthrough and seven genuine screenshots                                                             | Timed script, shot list and labeled screenshots                             | Video not yet recorded/uploaded; public repository and team fields incomplete |

The separate Track 03 website lists weights of 35/30/20/15, while the Devpost overview lists the four criteria without weights and contains newer dates. This package uses the four verified criteria rather than assuming those website weights govern judging. [Track site](https://gibc-9eb4d.web.app/topic-open.html).
