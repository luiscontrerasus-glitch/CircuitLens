# Technologies

- JavaScript ES modules, Node 24.14.1 (tested), HTTP server and built-in test runner.
- HTML, CSS, Canvas 2D, browser file input and fetch.
- Sharp 0.35.5: image validation/resizing/metadata removal.
- Ajv 8.20.0: strict JSON schema validation.
- OpenAI Responses API; gpt-4.1-mini-2025-04-14 pretrained multimodal model. Runtime requests implemented; successful live inference not yet verified.
- Original deterministic union-find breadboard graph and electrical rule code.
- Prettier 3.6.2; npm lockfile; Git; Dockerfile and Render blueprint (public deployment not completed).
- Codex assisted development and original programmatically generated synthetic illustrations.

No React, Python backend, custom trained detector, SPICE, sponsor API, real hardware sensor or third-party image dataset is used. Python was used for development file operations only, not product runtime.
