# Capture and edit checklist

- Reauthorize the blocked localhost browser review before any capture. Complete desktop, laptop, tablet, mobile, and reduced-motion inspection. Check browser console, clipping, selection, confirmation, export, and corrected results.
- Capture the shots in `submission/screenshots-cinematic/README.md`; select five only after reviewing the actual images.
- Record at 1440 × 1000 or a clean 16:9 viewport, 30 fps, with system/browser notifications and account pages outside the capture. Never show environment files or credentials.
- Rehearse the 2:45 script once. Use the six direct story controls for predictable timing; scroll also drives the same scenes. The footer motion control provides a static presentation of all six scenes.
- Start with a fresh reversed fixture. D1 correction is A=D12, B=D18; confirm and re-analyze. The first result must disappear as soon as the fields change.
- For review footage, use the explicitly simulated development provider. Do not claim its candidates came from the live OpenAI service. The harness is excluded from production.
- Keep synthetic labels, confidence caveats, and provenance readable. Use actual request time; no fake analysis delay, invented percentage, or simulated success presented as live.
- Save a local `circuitlens-cinematic-demo.mp4` only after real footage is recorded. No such file currently exists. Add captions from the script, trim pauses, and verify the complete exported video before upload.
- Recording/upload and event eligibility are separate; no competition submission or public deployment has been completed.
